# William Grady Hendrix — ePortfolio

Quarto portfolio for INEG 21003, published with GitHub Pages.

## Edit and preview
Open `grady-hendrix-eportfolio.Rproj` in RStudio. Edit `index.qmd`, `projects.qmd`, or `resume.qmd`, then run `quarto preview` in the Terminal.

## Publish updates
Run `quarto render`, then commit and push changes to `main`. GitHub Pages serves `/docs`.

The Projects page intentionally retains the two original Quarto starter posts required by the assignment. Replace or extend these when coursework projects are assigned.

`resume.pdf` is a public copy with the home address and reference contact details removed. The supplied original was not changed.
